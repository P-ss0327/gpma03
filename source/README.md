# 广东省项目管理协会官网

当前电脑端与手机端共用的 React + Vite 官网前端源码，整理于 2026-11-17。

## 运行

安装 Node.js 22，执行：

```sh
npm ci
npm run dev -- --host 0.0.0.0
```

## 构建与测试

```sh
npm run build
node --test tests/*.test.mjs
```

静态网页输出在 `dist/client`。该项目使用根路径资源，部署时请将静态文件放在站点根目录。不要直接双击源码 index.html。

## 功能说明

包含手机端响应式布局、新闻及团体标准展示、专家名录、相关下载、用户中心及在线申请演示。
登录测试账号：`user`，密码：`demo1234`。
注册、资料和申请记录是浏览器本地演示数据，不含正式业务后台，也不会向协会提交材料。正式上线需要接入后台认证、数据库及材料存储。

源码包不包含 node_modules、构建缓存、浏览器内的个人资料及申请记录。
