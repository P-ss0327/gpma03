## 共享组件

| 文件 | 职责与接入方式 |
| --- | --- |
| `src/SiteNavigation.jsx` | 官网一级导航和下拉菜单，读取 `siteNavigation.js`。 |
| `src/SiteSidebar.jsx` | 栏目导航；新闻页与下载页共同使用。传入 `title`、`items`、`value`、`label`。`items` 为 `{id,label,href?}`；有 `href` 时渲染链接，无 `href` 时通过 `onChange(id)` 进行本地筛选。 |
| `src/SitePagination.jsx` | 新闻页与下载页共同使用的分页。参数：`page`、`pageCount`、`onChange(page)`、`label`。复用官网的圆形40px按钮、选中/悬停/禁用状态及省略页码规则。 |
| `src/siteComponents.css` | 从原项目提取的侧栏和分页样式，是上述组件唯一的手写样式来源。不要在下载页再次覆盖分页或侧栏样式。 |
| `src/DownloadSearchPanel.jsx` | 资料检索内容；传入 `filters`、`draft`、`onDraftChange`、`onUpdate(patch)`、`onReset`。 |
| `src/DownloadFileRow.jsx` | 单个文件行；传入 `file`、`onPreview(file)`、`onDownload(file)`。根据 `canPreview` 决定是否显示预览按钮，不显示时仍保持下载右对齐。 |
| `src/DownloadsPage.jsx` | 组装页面、管理筛选/分页/URL和演示文本预览。 |
| `src/downloads.css` | 仅定义右侧下载内容和预览弹窗，不定义官网框架、侧栏、分页。 |

`SiteSidebar` 和 `SitePagination` 已在新闻与下载两个页面实际接入，非只为交接创建的未使用组件。浏览器核验两页分页的外框均为40×40px、50%圆角、选中背景为 `rgb(38,106,167)`。

## 数据模型

演示数据位于 `src/downloadData.js`。保留字段即可接入后端列表：

```js
{
  id: 1,
  title: '文件标题',
  category: '申报材料',
  tags: ['科技奖申报'],
  date: '2026-10-18T13:57:18',
  url: '/demo-downloads/gpma-demo-01.txt',
  filename: '演示-文件标题.txt',
  size: '0.6 KB',
  type: 'TXT',
  canPreview: true
}
```

`canPreview: false` 对应图2中仅下载的资料包，当前第5条为实际 ZIP，内含明确标识的演示说明；不含正式LOGO资产。所有标题、日期、分类及附件均为演示，不是协会正式发布材料。

当前预览加载 TXT 全文。接入 PDF、Office 或正式预览服务时，替换 `FilePreview`，依据 MIME/type 选择对应预览器；不要把当前文本预览器直接用于二进制附件。正式下载可直接使用后端提供的下载地址；跨域文件建议由服务端返回 `Content-Disposition`。
